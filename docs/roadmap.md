# 路线图

| 里程碑 | 内容 | 验收 |
|---|---|---|
| **M0 骨架** ✅ | pi-durable 运行时；主会话 / 任务分离；三档权限；租约；强制账本 | ADR-0001 的四项验证全部通过（2026-11-22） |
| **M1 可用** | 真实模型与自动切换（#1）；Web 对话界面（#2）；污点追踪（#3）；审批超时（#4）；ego 浏览器插件（#5）；租约对照实验（#6） | 网页上完成对话 → 派任务 → 审批 → 报告 |
| **M2 首批插件** | 邮箱、日程；权限决策准确率评测 | 端到端任务完成率 |
| **M3 飞书** | 机器人 Surface + 用户账号 Connector 双角色 | 提示注入测试集攻击成功率 = 0 |
| **M4 主动性** | 事件总线、调度器、收件分诊、目标驱动 | 主动漏斗各阶段转化率 |
| **M5 难接渠道** | 微信、QQ、WeLink | — |

微信与 QQ 没有官方个人 API，协议方案有封号风险，较稳的路线是在本机通过无障碍接口驱动客户端，因此放在最后，不阻塞前面的进度。
