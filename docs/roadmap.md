# 路线图

| 里程碑 | 内容 | 验收 |
|---|---|---|
| **M0 骨架** ✅ | pi-durable 运行时；主会话 / 任务分离；三档权限；租约；强制账本 | ADR-0001 的四项验证全部通过（2026-11-22） |
| **M1 可用** ✅ | 真实模型与自动切换（#1）；Web 对话界面（#2）；早期外部数据追踪（#3，后由 ADR-0018 取代）；审批超时（#4）；ego 浏览器插件（#5）；租约对照实验（#6）；163 邮箱（#12，原属 M2，提前完成） | 网页上完成对话 → 派任务 → 审批 → 报告（2026-11-22，v0.1.0） |
| **M2 首批插件** ✅ | 日程（#20）；权限决策评测 88/88（#21）；端到端评测（#22）；被拒后不换路重试（#27、#30）；主模型对比（#10） | 端到端任务完成率 33/33（2026-11-22，v0.2.0） |
| **M3 飞书** ✅ | 机器人 Surface：配对、指令、审批卡片（#32）；用户账号 Connector：OAuth 读写消息（#33）；提示注入测试集（#34）；早期权限规则修复（#44） | 提示注入攻击成功率 0/10（2026-11-22）；飞书真机：指令、审批卡片、OAuth 读账号全部走通（#54 修复 OAuth 换 token）（2026-11-23，v0.3.0） |
| **M4 主动性** ✅ | 长期记忆（#35）；调度器与通知中心（#36）；事件总线与分诊（#37）；漏斗统计与分诊评测（#38）；目标驱动复查（#48） | 漏斗可观测（/api/funnel + Web 漏斗条）；分诊准确率 91.7%、now 召回 100%（2026-11-22）；真实使用中的转化率待积累 |
| **M5 难接渠道** | 微信、QQ、WeLink | 方案讨论中 |
| **M6 少打扰与可观测** ✅ | 任务工具（#53）；权限说明与审批模型（#59，审批流程后由 ADR-0018 修订）与可信上下文（#65）；自适应巡检与 notify（#60）；定时任务（#71）；watch 盯梢（#61）；完整统计（#62）；Web 设置页（#63）；消息来源模板 RSS / JSON / GitHub（#72） | 审批模型 117 次判断误放 0、误问 0、注入 33/33 拦下（当时的离线样本）；统计页覆盖调用 / 任务 / 唤醒 / 日汇总；真实巡检、盯梢、定时任务冒烟通过（2026-11-23，v0.4.0） |
| **M7 自写插件** | 插件框架：清单、独立进程、HTTP 代发、安装审批、哈希与回滚（#86，ADR-0016）；Alter 编写插件与四层验收（#87）；首个案例小红书（#88）；统一来源轮询（#168）、宿主按声明接入插件（#169，ADR-0027）、常驻并发与受控密钥读取（#170，ADR-0028） | Alter 写出的插件经用户批准后以用户权限运行，无系统沙箱；来源与工具可在同一进程并发，密钥读取可审计 |
| **M8 记忆与回访** | 记忆改为索引 + 条目（#89，ADR-0014）；模型能力从目录识别、主会话压缩前存记忆（#104，ADR-0019）；反馈闭环：近况报告与每周回访同源题库（#90，ADR-0017，2026-11-24 暂停）；近况报告改为至少两个任务才发、摘要消息先浓缩（#111，ADR-0020）；后台运行（#110） | 索引常驻且不破坏提示缓存（主会话缓存命中 89%）；猜的记忆经回访确认或修正，答案改动可追溯、可撤销 |

微信与 QQ 没有官方个人 API，协议方案有封号风险，较稳的路线是在本机通过无障碍接口驱动客户端，因此放在最后，不阻塞前面的进度。
