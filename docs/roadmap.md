# 路线图

| 里程碑 | 内容 | 验收 |
|---|---|---|
| **M0 骨架** ✅ | pi-durable 运行时；主会话 / 任务分离；三档权限；租约；强制账本 | ADR-0001 的四项验证全部通过（2026-11-22） |
| **M1 可用** ✅ | 真实模型与自动切换（#1）；Web 对话界面（#2）；污点追踪（#3）；审批超时（#4）；ego 浏览器插件（#5）；租约对照实验（#6）；163 邮箱（#12，原属 M2，提前完成） | 网页上完成对话 → 派任务 → 审批 → 报告（2026-11-22，v0.1.0） |
| **M2 首批插件** ✅ | 日程（#20）；权限决策评测 88/88（#21）；端到端评测（#22）；被拒后不换路重试（#27、#30）；主模型对比（#10） | 端到端任务完成率 33/33（2026-11-22，v0.2.0） |

| **M4 主动性** | 事件总线、调度器、收件分诊、目标驱动 | 主动漏斗各阶段转化率 |
| **M5 难接渠道** | 微信、QQ、WeLink | — |

微信与 QQ 没有官方个人 API，协议方案有封号风险，较稳的路线是在本机通过无障碍接口驱动客户端，因此放在最后，不阻塞前面的进度。
