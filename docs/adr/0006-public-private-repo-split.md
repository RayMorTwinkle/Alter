# ADR-0006 公开仓库与私有仓库严格分离

- 状态：已接受
- 日期：2026-11-22

## 背景

Alter 开源，但开发过程会产生凭证、真实使用数据、个人记忆、原始开发日志。这些绝不能进入公开仓库。

## 决策

| 位置 | 内容 |
|---|---|
| 公开仓库 `Alter` | 代码、README、架构图、ADR、评测框架与合成测试集 |
| 私有仓库 | 凭证（sops + age 加密，私有仓库也不放明文）、开发日志、时间线、真实使用数据、个人记忆 |

- 两个独立仓库，在磁盘上并列，**不使用 submodule 互相嵌套**。
- 公开仓库启用 gitleaks pre-commit 钩子，CI 再扫描一次。
- 真实使用数据只以**聚合后的数字**对外（如"30 天处理 N 条消息"），不导出明细。
- 公开评测集只用合成数据。

## 后果

- 运行时通过环境变量或配置路径读取私有仓库中的解密凭证，公开代码中不出现任何真实路径或账号。

## 如何验证

gitleaks 在每次提交与 CI 中零命中；定期人工抽查公开仓库历史。
