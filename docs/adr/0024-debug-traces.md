# ADR-0024 记录模型实际输入，解释自主调度

- 状态｜已接受
- 日期｜2026-11-25
- 关联｜#132、ADR-0002、ADR-0019、ADR-0020

## 背景

时间线展示用户对话与任务进度。排查一次错误决定还需要看到当时的记忆索引、租用工具、内联报告、模型回退，以及触发回合的来源。这些内容会随运行状态变化，事后用当前设置重建可能得出不同的请求。

## 决策

在已有模型计量层记录主会话和任务会话的每次生成，以及主会话的上下文整理。网关在提供方完成消息转换和请求钩子后保存请求，在每次尝试结束时补上输出。回退和同模型重试逐次记录。其他提供方保存 SDK 规范化的消息，详情用 format 标识输入来源。若进程在中途退出，可查看已保存的输入和 pending 状态。

每条记录关联时间、会话、唤醒来源和可用的条目引用，保存消息顺序、系统指令、实际提供的工具、请求选项，以及模型返回的思考、正文、工具调用、错误、token 用量和延迟。工具执行可能跨过审批或重启，观察器在会话提交结果时，按会话和调用 ID 更新原记录。工具结果预览最多保存 20,000 个 UTF-16 码元并标记截断。若完整结果进入后续模型请求，该次请求的输入仍按实际内容保存。

本机独立 SQLite 数据库 `debug.sqlite` 使用内容表保存提示词、工具定义与历史消息。以类型和序列化内容计算 SHA-256，重复内容共用一行。每次调用按顺序保存消息哈希，详情查询逐项还原。这样回退、会话分叉、上下文压缩或较早 trace 过期时仍能独立读取。写入引用和清理引用均在事务中完成。启动时以及持续运行期间每日清除超过 14 天的 trace，同时清除失去全部引用的内容。内存宿主没有数据目录时使用内存数据库。

调度说明读取持久化的计划时间和运行状态。巡检保留上次选定间隔时的信号，按同一公式提供最新试算。近况报告说明每日检查时间、任务门槛和七天未互动暂停条件。定时安排、记忆整理、盯梢和每周回访分别暴露自己的规则。

## 隐私与访问

调试记录只存本机，数据库创建权限为 0600。已登录用户通过只读 API 查看，HTTP 响应禁用缓存。记录仅捕获模型请求体和返回内容，传输层的授权头与登录 Cookie 不进入采集流程。用户消息、工具参数、结果和模型输出中本身包含的敏感文字会原样出现。本策略只清理调试数据库，会话历史和用量记录沿用原有生命周期。
