Proactive personal agent

Durable work.

Ask Alter to follow up, read a schedule or watch for an update. A persistent main session delegates the work, checks tool permissions and keeps a record of the result.

Who can act?

A message enters through a surface or a connector. Where it came from determines how the runtime handles it.

Surface & connector

A verified surface accepts user instructions. Mail and feed connectors supply external records for triage. Content can inform a task, while authority comes from the user and the runtime.

Dispatch & lease

The main session delegates multi-step work and receives a compact result. For a short interaction, it can enable a capability or action on a sliding lease. The broker still checks the call.

Effects & approval

The broker distinguishes reads, writes and irreversible actions. Prior grants and the scope of a request determine when Alter asks for a decision. Capability-wide grants can cover irreversible actions.

Replay the regressions.

Same fixtures on the backup snapshot and the refactor. Expand a result to see what the probe actually counted.

Draft updates · history ID reads51,200 → 200

The fixture starts with 200 settled messages, then sends 256 cumulative text fragments for one new reply. Checking the history once when the draft starts preserves the guard against late fragments.

Exact replays · new reducer states32 → 0

After the last fragment, the harness sends its complete text another 32 times. The reducer reuses the existing state when the draft ID and text match. This counts object identity changes.

Ordered inserts · timestamp reads39,800 → 398

Across 200 chronological appends, a comparison with the last row replaces a full sort on the common path. Finding an existing ID and copying the timeline array still take linear work.

Calendar fixtures · correct next instant5/7 → 7/7

Two different starting dates hit the same missing Friday in Pacific/Apia. A Friday-only reminder used to land on Saturday. The scheduler now checks the candidate’s actual local weekday and continues to Friday, January 6, 2012.
